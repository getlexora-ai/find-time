04 / Detail + compose

Read in a popover. Edit in a modal. Never both at once.

Rules

What changes at each breakpoint, and why.

< 640px

Phone

Week strip is the default. Month = dots. Every modal is a bottom sheet. Bottom nav + FAB. Telemetry, sidebar and time-grid all hidden.

640 – 1023px

Tablet

Same mobile structure, wider agenda rows (4.5rem time gutter), compose becomes a centred modal, "New event" reappears in the toolbar.

1024px +

Desktop

Sidebar + mini-month appear, month becomes the default view, week/day time grids render, event taps open an anchored popover instead of a sheet.

1280px +

Wide

Telemetry column and the day-view right rail appear. At 1536px+ month chips regain their start time. Nothing structural — only more context.

Contrast

Lime on #121212 measures 15.94:1; body text at white/55 is 6.18:1. Orange #ff4400 is 5.42:1 on black but only 3.45:1 on white — so alert text on the light agenda switches to #cc3600 (5.13:1).

Keyboard

M / W / D switch view, T jumps to today, N opens compose, ← → step the period, Esc closes any layer. Focus ring is a 2px lime outline with 2px offset.

Targets

Mobile day cells 56px, day pills 58px, sheet buttons 44px. Month chips on desktop are 24px but the whole tile is clickable, so pointer users always have a large target.

Not colour alone

Protected carries a shield, clashes carry a triangle, AI carries a magic stick, breaks carry a cup. Category colour is always paired with a text label somewhere in the same view.
